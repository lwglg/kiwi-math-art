# Bundled fonts

**Vazirmatn** 33.0.3 (Regular, Bold) by Saber Rastikerdar, licensed under the SIL Open Font License 1.1
(see `OFL.txt`). It is used by the Persian (fa-IR) PDF; the other languages use the Typst built-in fonts.
Source: the `vazirmatn` package on npm. `kiwi-docs` passes this folder to Typst and ignores system fonts,
so the PDFs are identical on every machine.
