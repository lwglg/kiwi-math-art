# Точность транскрипции

Все формулы транскрибированы с увеличенного изображения (1600 × 1600) оригинальной работы; код на Python
реализует ровно то, что напечатано в PDF. Первое прочтение по изображению 800 × 800 содержало
несколько ошибок (например, `cos(107·Tᵣ + 5r)` вместо правильного `cos(10·Tᵣ + 5r)`) и было заменено.

| Элемент | Прочтение |
|---|---|
| Отображение пикселей, `F`, `A`, `B`, `u`, `v`, `E`, `Lₛ`, `Tᵣ`, `Uᵣ`, `Kₛ` | Ясно |
| Константа `2/58` в `θᵣ` | Плохо читается |
| Сдвиг `y − 8` в `Pᵣ`, `Qᵣ` (возможно, `y − 9`) | Плохо читается |
| Охват `λᵣ = 29/88 (1 + √(r/100)) − 3/2 \|(r−50)/45\|³` | Группировка выбрана так, чтобы контур тела замыкался |

Если у вас есть исходный текст формул, достаточно проверить эти три места в `feathers.py` и `background.py`.
