# Разработка и качество

- Менеджер пакетов: [`uv`](https://docs.astral.sh/uv/), Python 3.14 (`.python-version`).
- `make lint` — Ruff (`ruff.toml`); `make format` форматирует код.
- Стиль кода: Ruff форматирует и проверяет код, а также следит за пустыми строками вокруг определений (E30x). Ruff никогда
  не вставляет пустые строки между обычными операторами, поэтому `tools/spacing.py` применяет фирменный стиль внутри функций:
  одна пустая строка между операторами, кроме серий вызовов одной и той же функции и объекта, за которым сразу идут вызовы,
  настраивающие его (например, `parser = ...`, затем `parser.add_argument(...)`). `make format` запускает его перед
  `ruff format`; `make lint` — в режиме `--check`.
- `make typecheck` — строгий Mypy (`mypy.ini`).
- `make test` — Pytest (`pytest.ini`), падает при покрытии ниже 80 %.
- `make qa` запускает всё; GitHub Actions (`.github/workflows/ci.yml`) делает то же самое и
  дополнительно собирает PDF на всех пяти языках.
- У Python нет официальных LTS-версий, поэтому используется последняя стабильная.
- Полная отрисовка (`make image`) занимает несколько минут; для предпросмотра используйте `DECIMATION=4`.
- Ход выполнения: `make image` и `make pdf` выводят прогресс каждого этапа в stderr (в терминале — полоса с процентами,
  прошедшим временем и ETA; в логах и CI — одна строка на каждые 10 %). `make pdf-all` показывает шаги `[i/10]`
  и индикатор, пока Typst компилирует. `QUIET=1` (или `--quiet` у `kiwi` / `kiwi-docs`) отключает вывод.
